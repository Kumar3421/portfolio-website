# Kumar Shantanu | Portfolio

A high-performance, premium personal portfolio website featuring an **Apple Liquid Glass** design aesthetic. This project showcases software engineering expertise with a focus on Java, Spring Boot, Salesforce, and AI/ML.

## ✨ Key Features
- **Liquid Glass Aesthetic**: Deep blurs, high saturation, and squircle card designs.
- **Ordered Tech Satellites**: Live orbiting tech icons around the hero image (Java, Salesforce, GCP, Python, Slack, C, Spring).
- **Custom Animated Logo**: A two-layer Shiva brand logo with a 3D waving flag effect.
- **Settings Hub**: User-controlled toggles for Dark/Light mode and a global Animation Kill-Switch.
- **Responsive Mastery**: Fluid layouts optimized for all device sizes.
- **SEO Optimized**: Pre-configured with OpenGraph and Twitter meta tags for professional social sharing.

## 🚀 Deployment Guide

This project is a static site (HTML/CSS/JS), making it extremely easy to deploy for free.

### Option A: Vercel (Recommended)
1. Push this code to a **GitHub** repository.
2. Go to [Vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Click **Deploy**. Vercel will automatically detect the static files and provide a live URL within seconds.

### Option B: Netlify
1. Push this code to **GitHub**.
2. Go to [Netlify.com](https://netlify.com) and click **"Add New Site"**.
3. Link your GitHub repository.
4. Set the build command to `None` and publish directory to `.` (Current directory).
5. Click **Deploy**.

## 🛠️ Local Development
To run this project locally without a web server:
1. Clone the repository.
2. Open `index.html` in any modern browser.

Alternatively, use a local server for the best experience:
```bash
npx http-server -p 3456 -c-1
```
